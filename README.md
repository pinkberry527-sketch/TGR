# 🌐 Ruth Idehen Portfolio

A modern and responsive personal portfolio website built with React, Tailwind CSS, and Framer Motion.

This portfolio showcases my skills, projects, UI/UX design style, and frontend development journey through interactive animations, glassmorphism effects, and smooth user experience.

---

## ✨ Features

* Responsive modern UI
* Dark mode support
* Animated hero section
* Scroll reveal animations
* Skills progress indicators
* Interactive project carousel slider
* Auto-sliding project showcase
* Project modal popup
* Functional contact form with EmailJS
* Success toast notifications
* Floating back-to-top button
* Smooth scrolling navigation
* Glassmorphism design effects
* Framer Motion animations

## 🚀 Installation

Clone the repository:

```bash
git clone 
```

Navigate into the project folder:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 📬 Contact Form Setup

This project uses EmailJS for email functionality.

### Install EmailJS

```bash
npm install @emailjs/browser
```

### Create an EmailJS account

Visit:

https://www.emailjs.com/

Then:

* Create an account
* Connect your email service
* Create an email template
* Copy your:

  * Service ID
  * Template ID
  * Public Key

Add them inside your contact component.
